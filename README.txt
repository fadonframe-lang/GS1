GS1 DataMatrix v5 PWA — Android / браузер

Это версия v4 Compact с PWA: интерфейс, генератор, камера и ASCII 29 остаются прежними.

УСТАНОВКА НА ANDROID (Chrome)
1. Распакуйте папку и загрузите ВСЕ ее содержимое на HTTPS-хостинг (например, GitHub Pages или Cloudflare Pages).
2. Откройте HTTPS-адрес на телефоне в Chrome (нужен интернет один раз).
3. Дождитесь загрузки страницы; в меню Chrome выберите «Установить приложение» или «Добавить на главный экран». Формулировка зависит от версии браузера.
4. Запустите установленное приложение. После успешного кэширования всех файлов оно работает без интернета.
5. При первом сканировании разрешите доступ к камере.

ВАЖНО
- Прямой запуск index.html через file:// продолжает работать как прежняя v4, но PWA-установка и сервис-воркер там НЕ действуют, а камера может быть недоступна.
- Для установки по HTTPS необходимо разместить приложение на хостинге. Архив сам по себе APK не является.
- Доступ к интернету не нужен для самой генерации и локального декодирования; код маркировки никуда не отправляется.
- Если браузер не предлагает установку, попробуйте меню Chrome > «Добавить на главный экран».
- Если после обновления файлов изменения не появляются, обновите страницу с сетью; service-worker кэшируется и обновляется на следующем запуске.
- Для доступа к камере браузер требует защищенный контекст (HTTPS либо localhost).
- При размещении на GitHub Pages не загружайте секретные персональные данные: исходный HTML/JS будет общедоступен, но введенные коды приложение на сервер не отправляет.

Файлы:
index.html, style.css, script.js, scanner.js, vendor/datamatrix.js — сама программа
manifest.webmanifest — описание PWA
service-worker.js — офлайн кэш
pwa.js — регистрация офлайн режима
icons/ — иконки 192, 512 и Apple touch
